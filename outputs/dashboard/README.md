# Dashboard screenshot

A genuine screenshot must be captured from the running Streamlit application on the author's machine. No screenshot was included in the supplied archive, so this folder intentionally does not contain a fabricated image.

1. Start the app: `streamlit run dashboard/app.py`.
2. Open `http://localhost:8501`.
3. Set a representative date range and category filter.
4. Capture the Executive Overview and one detailed analytics page using Windows Snipping Tool (`Win + Shift + S`).
5. Save the images here as `executive_overview.png` and `analytics_detail.png`.
